# Прогнозирование длительности поездок на такси в Нью-Йорке

## 🎯 Цель проекта
Разработать оптимальную модель машинного обучения для точного прогнозирования длительности поездок на такси в Нью-Йорке на основе временных и географических признаков. Построить полный пайплайн: от разведочного анализа данных (EDA) и предобработки до ансамблирования моделей и построения нейросетей.

## 📊 Описание данных
В проекте используется датасет поездок Yellow Taxi за первую половину 2016 года.
Основные признаки:
* `pickup_datetime` / `dropoff_datetime` — время начала и окончания поездки.
* `pickup_longitude` / `pickup_latitude` / `dropoff_longitude` / `dropoff_latitude` — географические координаты.
* `passenger_count` — количество пассажиров.
* `store_and_fwd_flag` — флаг сохранения данных в памяти автомобиля.
* `trip_duration` — длительность поездки в секундах (**целевая переменная**).

## 🛠️ Этапы реализации

### 1. Разведочный анализ данных (EDA)
* Проверена целостность данных (отсутствие пропусков).
* Выявлен сильный логнормальный скос целевой переменной `trip_duration`.
* Изучены распределения поездок по времени: пик активности приходится на 18:00–19:00.

### 2. Предобработка и Feature Engineering
* **Защита от утечки данных:** Разделение на `train` и `test` выполнено строго до расчета квантилей для фильтрации аномалий.
* **Временные признаки:** Выделены час, день недели и месяц. Для часов и дней недели применено **циклическое кодирование (Sine/Cosine)**, чтобы модель понимала близость 23:00 и 00:00.
* **Гео-признаки:** Рассчитано реальное расстояние между точками по **формуле Гаверсина (Haversine distance)** в километрах.
* **Фильтрация аномалий:** Удалены логические ошибки (короткие поездки на большие дистанции и наоборот), а также экстремальные выбросы по 1-му и 99-му квантилям на обучающей выборке.
* **Масштабирование:** Применена стандартизация признаков через `StandardScaler`.

### 3. Моделирование и ансамблирование
Обучены и сопоставлены следующие архитектуры:
1. **Линейная регрессия** — базовый линейный алгоритм.
2. **KNN Regressor** — метод ближайших соседей.
3. **Random Forest** — бэггинг над деревьями решений.
4. **Gradient Boosting** — последовательное построение ансамбля деревьев.
5. **Нейронная сеть (MLP)** — полносвязный многослойный перцептрон на Keras/TensorFlow с регуляризацией `EarlyStopping`.
6. **Voting Regressor** — финальный ансамбль, усредняющий прогнозы лучших моделей.

## 📈 Результаты эксперимента

В ходе работы над проектом были протестированы различные подходы: от базовых линейных алгоритмов до современных ансамблевых методов и нейронных сетей.

| Модель | MAE (мин) | $R^2$ |
| :--- | :--- | :--- |
| Линейная регрессия | 4.3 | 0.59 |
| KNN Regressor | 3.9 | 0.65 |
| Нейронная сеть (MLP) | 3.6 | 0.69 |
| **Random Forest** | **3.6** | **0.70** |
| **Gradient Boosting** | **3.6** | **0.70** |
| **Voting Regressor** | **3.6** | **0.70** |

### 🔍 Основные выводы:

1. **Нелинейность данных:** Линейная регрессия показала худший результат ($R^2 = 0.59$), так как не способна уловить сложные городские условия (пробки, часы пик).
2. **Лидеры предсказаний:** Алгоритмы **Random Forest**, **Gradient Boosting** и ансамбль **Voting Regressor** разделили первое место ($R^2 = 0.70$), показав минимальную ошибку — всего **3.6 минуты**.
3. **Нейросеть (MLP):** После нормализации признаков показала отличную точность ($R^2 = 0.69$), практически сравнявшись с ансамблями деревьев.
4. **Итог:** Средняя ошибка в ~3.5 минуты — отличный показатель для реального трафика Нью-Йорка. Для практического применения рекомендуются **Gradient Boosting** или **Random Forest** как самые быстрые и стабильные модели.
